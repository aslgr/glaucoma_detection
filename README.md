# Glaucoma Detection

A computer vision project focused on detecting glaucoma from retinal fundus images by comparing traditional image processing and machine learning techniques with deep learning approaches.

## Dataset

This project uses the [RIM-ONE DL](https://github.com/miag-ull/rim-one-dl) dataset, containing retinal fundus images labeled as normal or glaucomatous.
